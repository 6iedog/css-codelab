页面标题

一句话说清这个特性到底改变了什么，以及读者在这页能看到什么。示例：contain 不改变任何外观，它只做一件事——告诉浏览器「这个盒子里外互不影响」。

这一节在讲什么

先讲机制，不要先给效果。这一段说明这个特性切断了什么、改变了什么，以及为什么会这样。属性名第一次出现时用 contain 这种写法链到 MDN，之后再用普通 行内代码 就行——同一个属性一页只链一次。

需要并列的第二种写法、或第二层细节，就再加一个段落；要分小节时用下面这种 h3，并同步加进左侧目录。

/* 需要单独展示的机制代码，放这里 */
.target { contain: layout; }   /* .hl 标起作用的那一行，.cm 标注释 */
